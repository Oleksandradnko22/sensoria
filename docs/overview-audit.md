# Аудит вкладки «Огляд» (ParticipantOverview)

2026-10-07. Код не менялся. Прочитан весь `ParticipantOverview.tsx` (1135 строк) + живая проверка в браузере.

## Что на экране (сверху вниз)
1. Главная карточка: «Продовжити / Почати» (одно действие) или «Ваш наступний крок» (пустое состояние с медитацией).
2. «Ваш емоційний профіль» + «Моє навчання» (до 3 элементов).
3. «Підібрано для вас» (до 3, бейдж РЕКОМЕНДОВАНО).
4. «Може бути корисно» (только при повторяющемся поведении в медитациях).
5. «Останні повідомлення» + «Ваші спостереження».

Живая проверка: все блоки рендерятся, состояния загрузки сменяются данными, консольные ошибки — только известные 400 (демо-id в uuid-колонки). Сбоев ссылок/кнопок не замечено.

## A. Данные (самое важное)
1. **Демо смешано с реальным.** «Робота зі стресом — 0% пройдено» в «Моє навчання» и сообщения «Андрій Коваленко» (10 серпня) — статические демо-данные рядом с настоящими сообщениями «Маша». Демо-сообщения добавляются к реальным всегда (`slice(0,3)`), а гайды/медитации берутся из статического `enrollments`. У реального пользователя это выглядит как чужие/выдуманные данные. **Приоритет: высокий.**
2. **«Моє навчання» на новом устройстве** показывает 0%, пока программу не откроют (прогресс подтягивается только в плеере). Известный пункт.
3. **Две вкладки/источника для прогресса программ**: summary из контекста + синхронное чтение localStorage в `correctedEnrollments`. Расхождение возможно.
4. `fetchAllSectionViews` вызывается дважды (общий эффект и эффект главного гайда). Лишний запрос.
5. «Ваші спостереження» показывает только счётчик («У вас вже є збережені…») — без числа/даты; блок малоинформативен.

## B. Техника
1. Файл 1135 строк, много исторических комментариев про фиксы; логика выбора главной карточки, превью, сообщений, наблюдений — всё в одном компоненте. Кандидаты на вынос в хуки: `usePrimaryAction`, `useRecentMessages`, `useObservationsSummary` (чистая логика — в `utils/`, с тестами).
2. `correctedEnrollments` не мемоизирован и читает localStorage при каждом рендере.
3. Локальные обёртки `pluralSteps`/`pluralMaterials` над `pluralUk` — можно вызывать напрямую.
4. Три карточки рекомендаций (курс/медитация/гайд) — копипаста одной кнопки; один компонент `RecommendationCard` убрал бы ~60 строк.
5. Нет тестов на выбор главной карточки в самом компоненте (логика частично в `lib/dashboardPriority`, она протестирована).

## C. Дизайн / UX
1. Цвет и иконки: эмодзи как иконки (📘🧘📄) вместо единого набора — непоследовательно с остальным кабинетом.
2. Разные заголовки: «Ваш емоційний профіль» — подпись 13px, остальные блоки — h2 17px. Иерархия разная.
3. «Емоційне вигорання» (профиль) против «виснаження» в подписи — расхождение терминов (известный вопрос с «Вигорання/Виснаження»).
4. Главная карточка: при `Почати` / `Продовжити` текст дублируется (подпись + кнопка). Можно оставить только кнопку.
5. Пустые состояния короткие и без действий («Тут з'явиться те, що ви почнете…») — можно добавить кнопку «Відкрити каталог».
6. Сообщения: аватар по первой букве, нет перехода в конкретный диалог — «Усі →» открывает общий список.
7. Узкая ширина (~480px): блоки складываются в одну колонку нормально; проверить на 360px и в Safari вручную.

## D. Что убрать / добавить
- Убрать: демо-сообщения и демо-enrollments для реальных пользователей (под флаг `VITE_SHOW_DEMO_PROGRAMS`, как в каталоге).
- Добавить: клик по сообщению → нужный диалог; число/дата последнего наблюдения; кнопки в пустых состояниях.
- Не трогать: логику «ровно одно главное действие», защиту от «мигания» рекомендаций при загрузке.
