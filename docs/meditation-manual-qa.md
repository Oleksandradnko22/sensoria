# Медитации: ручная проверка в браузере (Safari обязателен)

Юнит-тесты и `tsc` не доказывают, что звук и экран работают вместе. Ниже то, что
**нужно пройти руками** перед тем, как считать медитации готовыми. Основной
браузер: **Safari (macOS)**, затем Chrome. Если один пункт не прошёл, пометь,
что именно и в каком браузере.

## Что проверено автоматически, а что нет

| Проверено тестами (`node --test`) | Только вручную |
|---|---|
| Состояние сессии: старт, завершение, остановка, повтор (`meditationSession.test.ts`) | Реальное воспроизведение, пауза, перемотка |
| «До» и «после» хранятся отдельно, повтор не перезаписывает прошлую сессию | Синхронность мини-плеера и полного экрана |
| «После» сохраняется даже без «до» | Поведение при переключении вкладок и сворачивании |
| Итог звучит как личный опыт, без слов об эффекте | Safari: фон, блокировка экрана, автозапуск |
| Восстановление после сбоя/мусора в хранилище | Перезагрузка и «назад/вперёд» |
| Правило «когда сессия окончена» (`isSessionOver`) | Экран «Текст практики» |
| Правило возобновления позиции (`meditationResume`) | Скачивание офлайн на реальном устройстве |
| Ключи проверки состояния, чтение старых записей | |
| Обязательность транскрипта для голосовых медитаций | |

## Единый источник звука (как устроено)

- Единственный основной `<audio>` создаётся один раз в `MeditationPlayerProvider`
  (`context/MeditationPlayerContext.tsx`). Полный экран и мини-плеер только читают
  и управляют им через `useMeditationPlayer()`.
- Окно «Зберегти офлайн» (`MeditationDownloadPicker`) раньше запускало свой
  отдельный звук поверх основного. Теперь при старте превью оно ставит основной
  плеер на паузу. **Проверить вручную** (пункт Б5).

## Подготовка

1. Войди как участник, открой «Моє навчання → Медитації → Швидке заземлення».
2. Открой Консоль Safari (Develop → Show JavaScript Console) и следи за ошибками
   на протяжении всей проверки.

## А. Базовый цикл

- [ ] А1. Старт: «Почати практику» → при желании пройти «Як ви почуваєтесь зараз?» → звук идёт.
- [ ] А2. Пауза: звук остановился, время не бежит, кнопка показывает «Відтворити».
- [ ] А3. Продолжить: идёт с того же места.
- [ ] А4. Перемотка ±15 с и ползунок: позиция и время меняются сразу.
- [ ] А5. Таймер (5/10/15 мин): отсчёт идёт только при воспроизведении; по нулю звук плавно затихает и открывается итог.
- [ ] А6. Естественное завершение (долистать ползунок почти до конца): автоматически открывается итог.
- [ ] А7. «Завершити» в плеере: подтверждение, затем экран «зупинено», не «завершено»; практика остаётся доступной для продолжения.
- [ ] А8. Ошибка: отключи сеть в Network (Offline) до старта → видно «Не вдалося завантажити аудіо» и «Спробувати ще»; после включения сети кнопка запускает звук.

## Б. Мини-плеер и полный экран (одна сессия звука)

Закрой полный экран крестиком, пока звук играет: должен появиться мини-плеер.

- [ ] Б1. Play/pause синхронны: нажать паузу в мини-плеере, открыть полный экран, там пауза; и наоборот.
- [ ] Б2. `currentTime` совпадает на обоих (допуск 1 с).
- [ ] Б3. Длительность одинаковая.
- [ ] Б4. Перемотка в полном экране сдвигает мини-плеер и наоборот.
- [ ] Б5. Открыть «Зберегти офлайн» (выбор фона) при играющем звуке и нажать превью: основной звук **ставится на паузу**, одновременно не играют два звука. Закрыть окно: основной остаётся на паузе.
- [ ] Б6. Завершение: когда практика закончилась при закрытом экране, мини-плеер показывает конец; открытие полного экрана ведёт сразу на итог, не на начало.
- [ ] Б7. Многократно открыть и закрыть полный экран (5–10 раз): не появляется второй звук, не удваивается эхо. В Safari проверить в Activity/Web Inspector → Media, что `<audio>` один.
- [ ] Б8. Повторно открыть ту же медитацию из «Моє навчання» («Продовжити»), пока она играет: открывается `player`, не интро; звук не перезапускается.

## В. Перезагрузка, навигация, вкладки

- [ ] В1. Перезагрузка страницы во время практики: звук останавливается; при повторном открытии есть «Продовжити з M:SS» (позиция сохраняется раз в ~8 с, при уходе вкладки в фон и при `pagehide`).
- [ ] В2. Назад/вперёд браузера: приложение не ломается; при возврате состояние плеера корректное, нет «зависшего» мини-плеера.
- [ ] В3. Переключение вкладок Safari на 30+ секунд и возврат: звук продолжает идти (или стоит на паузе, если так решила система), позиция и таймер верны.
- [ ] В4. Блокировка экрана (особенно iPhone Safari): звук продолжает идти; на экране блокировки есть Play/Pause и ±15 с.
- [ ] В5. Закрыть вкладку и открыть заново: позиция восстановилась, чек-ин не потерялся (смотри Г).

## Г. Проверка состояния до и после

- [ ] Г1. До: выбрать состояние и интенсивность 1-5. Старт.
- [ ] Г2. После: на итоге та же шкала 1-5. Ниже показывается «Ви відзначили напругу X з 5 до практики і Y з 5 після» **и** фраза «Це ваш особистий досвід…» (никаких слов «помогло», «эффект»).
- [ ] Г3. Пропустить «до» совсем, ответить только «после»: ответ сохранён (в «Ваші спостереження» пара появится только если есть оба значения).
- [ ] Г4. Повторить медитацию («Повторити»): прошлая пара не изменилась. В Supabase `meditation_mood_checkins` — отдельная строка на каждую сессию.
- [ ] Г5. Перезагрузить на экране итога: «до» и «после» на месте.
- [ ] Г6. «Що змінилося?» (чипы): выбор сохраняется, снимается повторным нажатием.

## Д. Транскрипт

- [ ] Д1. У медитации без подтверждённого текста раздел «Текст практики» **не показывается** (автораспознавания речи нет).
- [ ] Д2. После добавления подтверждённого транскрипта (см. ниже) в плеере появляется раскрывающийся «Текст практики»; читается с клавиатуры и скринридером.

### Как добавить транскрипт (пока нет редактора автора)

В `src/data/meditations.ts` у записи медитации добавить:

```ts
transcript: {
  text: "Первый абзац.\n\nВторой абзац.",
  status: "confirmed",
  confirmedBy: "Имя автора",
  confirmedAt: "2026-10-06T12:00:00Z",
},
```

Текст пишет и вычитывает автор. Затем убрать id медитации из `KNOWN_MISSING` в
`src/data/meditationTranscripts.test.ts`. Для `guided` и `minimal` транскрипт
обязателен (тест не даст добавить такую медитацию без него).

## Е. Офлайн

- [ ] Е1. «Зберегти офлайн» без фона: файл сохраняется, прогресс идёт, затем «Збережено».
- [ ] Е2. С фоном: сохраняется смешанный файл; в плеере фон не накладывается второй раз.
- [ ] Е3. Отключить сеть: офлайн-копия играет.
- [ ] Е4. Места нет (эмуляция/реальное заполнение): показывается «Недостатньо місця на пристрої».

## Отчёт

Для каждого непройденного пункта: браузер + версия, шаги, что ожидалось, что
получилось, скриншот или видео, текст ошибки из консоли.
