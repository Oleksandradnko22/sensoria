# Программы: ручная проверка (Safari обязателен)

Тесты и `tsc` не проверяют реальную работу плеера, записи в базу и редактора.
Пройди руками и отметь, что не сработало (браузер, шаги, скриншот, консоль).

## Автор: публикация и редактирование

- [ ] А1. «Надіслати на модерацію» с пустым описанием, пустым модулем, видео-уроком без транскрипта: показывается список конкретных проблем, ничего не отправлено.
- [ ] А2. После исправления отправка проходит.
- [ ] А3. «Зберегти чернетку» работает и с неполной программой.
- [ ] А4. Модуль с уроками и пустой строкой названия: при сохранении название становится «Без назви», уроки не пропали. Перед публикацией просит назвать.
- [ ] А5. Число уроков в модуле считается само (поле неактивно, когда есть уроки), длительность подставляется из уроков, если все указали минуты.
- [ ] А6. Опубликованная программа: удалить урок, поменять тип, переключить «обов'язковий»: перед сохранением появляется подтверждение с перечнем и числом участников с прогрессом. «Отмена» ничего не сохраняет.
- [ ] А7. Переставить модули/уроки местами и сохранить: подтверждения нет, у участника прогресс остался на тех же уроках.

## Участник: урок и запись

- [ ] Б1. Отключить сеть (Network → Offline), поставить «Корисно», написать рефлексию, ответить на практику, поставить закладку: появляется чёрная плашка «Не вдалося зберегти …», рефлексия остаётся в поле.
- [ ] Б2. С сетью те же действия сохраняются, после перезагрузки на месте.
- [ ] Б3. Аудио в уроке: нет кнопки «скачать» в меню плеера и контекстного меню по правому клику; скорость воспроизведения доступна.
- [ ] Б4. Видео: старт, пауза, возобновление с сохранённой позиции после перезагрузки.
- [ ] Б5. Перестановка модулей автором не сдвигает прогресс участника.
- [ ] Б6. Добавление автором обязательного урока в завершённую программу: у участника процент меньше 100, программа снова «в процессе» (это ожидаемо, как в тесте `contentProgress.test.ts`).

## Доступ и защита (до запуска платных программ)

- [ ] В1. Вне аккаунта (окно инкогнито) убедиться, что содержимое платной программы **доступно** (так сейчас). Это известная проблема, см. `docs/program-access-control.md`.
- [ ] В2. После внедрения серверного допуска: гость, участник без покупки, с покупкой, автор, админ.
